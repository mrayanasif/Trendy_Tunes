# 🎵 Trendy Tunes

**Discover your next favorite track with Trendy Tunes!**

Trendy Tunes is a music website designed to provide users with a platform to explore music, browse albums, watch video content, and share their reviews.

## ✨ Features

* 🎶 **Music Library** — Browse available music.
* 💿 **Albums** — Explore music albums.
* 🎬 **Video Content** — Access video content through the website.
* 👤 **User Authentication** — Register and log in to an account.
* ⭐ **Reviews** — Share feedback and reviews.
* 📱 **Responsive Design** — Designed for a convenient browsing experience across different screen sizes.

## 🛠️ Technologies Used

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** PHP
* **Database:** MySQL
* **Development Environment:** XAMPP
* **Version Control:** Git and GitHub

## ⚙️ Installation and Setup

Follow these steps to run Trendy Tunes locally.

### 1. Install a Local Server

Install [XAMPP](https://www.apachefriends.org/) to run PHP and MySQL on your computer.

### 2. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/Trendy-Tunes.git
```

Replace `YOUR-USERNAME` with your GitHub username.

### 3. Move the Project

Place the project folder inside XAMPP's `htdocs` directory.

For example:

```text
C:/xampp/htdocs/Sound/
```

### 4. Start Apache and MySQL

Open the XAMPP Control Panel and start:

* Apache
* MySQL

### 5. Set Up the Database

1. Open phpMyAdmin at `http://localhost/phpmyadmin/`.
2. Create a MySQL database named `trendy_tunes`.
3. Import your database SQL backup, if available.
4. Update the database connection settings in your PHP project to match your local MySQL configuration.

**Important:** Keep database credentials private. Never commit passwords or private database backups to a public repository.

### 6. Run the Website

Open your browser and visit:

```text
http://localhost/Sound/
```

If your project folder has a different name, replace `Sound` with that folder name.

## 🔐 Security
